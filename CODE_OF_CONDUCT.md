# Code of conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion technical. Harassment, personal attacks, and posting others' private information are not tolerated.

Report violations privately to the repository maintainers through a [GitHub Security Advisory](https://github.com/mherzog4/callcraft/security/advisories/new) or a direct message to the maintainer on GitHub. Maintainers will review and respond, and may remove comments, commits, issues, or pull requests, or block accounts for violations.
